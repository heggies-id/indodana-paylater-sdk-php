# Indodana Paylater SDK for PHP

See how to integrate [here](https://dev.indodana.id/indodana-paylater/integration/integrate-with-php-sdk)

## Requirements

- PHP 8.3 or later (tested on 8.3 and 8.4; 8.5 is tested as experimental).

### Upgrading from 1.x

Version 2.0.0 raises the minimum PHP version from 5.6 to 8.3. This is a breaking change: projects on PHP 8.2 or older stay on the 1.x line, which Composer keeps installing for them. Upgrade PHP first, then require `indodana/indodana-paylater-sdk:^2.0`.
